# BioLand-US

Contractual land access and prospective U.S. perennial-biomass mobilisation.

## The question

BioLand-US asks a practical implementation question:

> When a techno-economic model allocates land to perennial biomass, how much of that prospective allocation can also be supported by compatible agricultural land and voluntary contractual participation?

The model does not replace or re-optimise the upstream resource allocation. It adds an explicit implementation layer.

## Scientific logic

The framework keeps four quantities distinct:

``` text
Techno-economic biomass allocation
        ↓
Compatible agricultural land
        ↓
Contractually accessible land
        ↓
Prospectively mobilised biomass
```

This makes it possible to distinguish technical allocation from land compatibility and actual access through voluntary contracts.

## Evidence

The model combines:

- POLYSYS biomass allocation from the 2023 Billion-Ton analysis;
- 2022 U.S. Census of Agriculture land data;
- county cash-rent context;
- experimental evidence on landholder contract participation; and
- county-level spatial matching.

## Reproducibility

The public repository contains the code, frozen non-disclosive behavioural parameters, data-access documentation, verification scripts and manuscript-facing outputs while respecting restrictions on respondent-level records.
