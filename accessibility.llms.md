# Accessibility

Accessibility information for EKO Perspectives.

*Last updated: 23 September 2026.*

I want EKO Perspectives to be usable by as many readers as possible, across different devices, browsers and ways of navigating the web.

The site is designed with responsive layouts, readable contrast, keyboard-accessible navigation, descriptive page titles and alternative text for images where appropriate. I also try to keep articles visually simple and avoid unnecessary interface elements that make reading harder.

Accessibility is an ongoing process rather than a one-time check. If you encounter a page that is difficult to read or navigate, an image without useful alternative text, a broken link, poor contrast, or another accessibility problem, please email <e.ofori1@universityofgalway.ie>. If possible, include the page address and a short description of what went wrong.

I will use that feedback to improve the site where I reasonably can.
