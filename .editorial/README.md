# EKO editorial system

The canonical editorial workflow for EKO Perspectives is:

- `.editorial/EKO_EDITORIAL_WORKFLOW_v2.3.md`

Repository-level assistants should also follow:

- `AGENTS.md`
- `.github/copilot-instructions.md`
- `.editorial/story-engine-library.md`
- `.editorial/EKO_PERSPECTIVES_EDITORIAL_PLAN.md`

`EKO_EDITORIAL_WORKFLOW_v2.3.md` supersedes the former v2.2 workflow and the older separate `pre2015-prose-voice` / `ai-slop-editing-pass` chain. Do not run those older systems in parallel with v2.3.

The supporting editorial files are references, not competing workflows. If any older planning note or reference conflicts with v2.3, v2.3 is authoritative.

For publication work, preserve the approval gate: new posts remain `draft: true` until Elvis Kwame Ofori explicitly approves publication, and already-published posts are not altered without explicit approval.
